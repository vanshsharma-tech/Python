# Array Interview Questions

---

## ✅ Easy Level

1. Find the **largest** and **smallest** element in an array.
2. Find the **second largest** element.
3. Reverse an array.
4. Check if an array is **sorted**.
5. Find the **sum of all elements**.
6. Count **frequency of each element**.
7. Find the element that appears **once** (all others appear twice → XOR trick).
8. Remove duplicates from a sorted array.
9. Find missing number in `1…n` sequence.
10. Merge two sorted arrays.

---

## ✅ Medium Level

1. Find the **maximum subarray sum** (Kadane’s Algorithm).
2. Find the **subarray with given sum**.
3. Find **pair of elements** with given sum.
4. Sort array of **0s, 1s, and 2s** (Dutch National Flag).
5. Rotate array by `k` positions.
6. Move all **zeros to the end**.
7. Find the **intersection** of two arrays.
8. Find the **union** of two arrays.
9. Find the **longest subarray** with given sum.
10. Find the **majority element** (appears > n/2 times → Boyer-Moore Algorithm).
11. Find the **equilibrium index** (sum left = sum right).
12. Find the **leaders** in an array (element greater than all right elements).
13. Count inversions in array (Merge Sort trick).
14. Find the **stock buy and sell** for max profit.
15. Spiral print of a 2D array.

---

## ✅ Hard Level

1. Find the **maximum product subarray**.
2. Find the **longest consecutive subsequence**.
3. Find the **trapping rainwater**.
4. Find the **maximum sum circular subarray**.
5. Find the **subarray with XOR = K**.
6. Find the **median of two sorted arrays**.
7. Find the **smallest subarray with sum > K**.
8. Find the **longest subarray with equal 0s and 1s**.
9. Find the **largest rectangle in histogram**.
10. Find the **maximum sum rectangle in a 2D matrix**.
11. Search in a **rotated sorted array**.
12. Find the **minimum number of swaps** required to sort an array.
13. Implement **merge intervals**.
14. Find **kth smallest/largest element** (Heap/QuickSelect).
15. Maximum sum path in two arrays.

---

## 📌 Bonus: Tricky / Pattern-Based

* Sliding window problems (max sum of size K, first negative in every window, etc.)
* Prefix sum based problems (subarray sum divisible by k).
* XOR-based problems (two non-repeating numbers, find duplicate in 1…n, etc.).

---

🔥 If you master these, you’ll cover **90% of array questions** asked in interviews.
